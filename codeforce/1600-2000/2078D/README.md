# Scammy Game Ad
## 링크
[문제 바로가기](https://codeforces.com/problemset/problem/2078/D)

## 사용 알고리즘
- 백트랙킹
- 그리디

## 풀이
- 인원 배치를 정할 때 이후 연산자들을 보고 더 높은 *가 가장 먼저 나오는 방향으로 turn을 정하면 해결되는 문제다.
뒤에서 부터 turn을 정하며 앞으로 이동하는 방식으로 구현해 반복되는 연산을 최소화하였다.

## 복잡도
- 시간: O(n)
- 공간: O(n) 

## 한 줄 회고
문제의 조건 중 * 제한이 2이상 3이하라는 것에 집중하면 쉽게 풀 수 있는 문제였다.
