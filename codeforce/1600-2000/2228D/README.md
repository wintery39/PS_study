# Sanae, Cross and Color

## 링크
[문제 바로가기](https://codeforces.com/problemset/problem/2228/D)

## 사용 알고리즘
- 힙
- 투포인터

## 풀이
- x좌표 기준으로 정렬한다. 시작 x를 0으로 생각하고 이를 기준으로 왼쪽에서 오른쪽으로 x를 이동시킨다(증가시킨다). 즉, 오른쪽에 있던 점들이 하나씩 왼쪽으로 이동하게 된다. 이 경우 한번 한번마다 (왼쪽의 y min과 오른쪽의 y min중 큰 값)<= (점들) < (왼쪽의 y max와 오른쪽의 y max중 작은 값) 해당 식을 만족하는 점들의 y좌표 수를 구하면 답을 구할 수 있다.
 좌표를 그대로 두지 않고 순위(rank)로 바꾼 이유는 사이에 있는 점들의 개수를 빨리 계산하기 위해서이다.

## 복잡도
- 시간: O(nlogn) 
- 공간: O(n) 

## 한 줄 회고
구현하는 중 x좌표는 굳이 rank로 바꿀 필요가 없다는 것을 깨달았다. 구현하기 전에 최적화된 방식인지 검증하는 것이 중요하다는 것을 느꼈다.
