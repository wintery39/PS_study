# Restoration of string

## 링크
[문제 바로가기](https://codeforces.com/problemset/problem/886/D)

## 사용 알고리즘
- 문자열 처리

## 풀이
- 첫 문자를 기준으로 bucket을 만들어 a로 시작하는 단어, b로 시작하는 단어..를 구한다. 이 때 a로 시작하는 단어가 여러개일 경우 a로 시작하는 단어 중 다른 모든 단어를 substring으로 포함하는 단어를 선택한다. 그렇지 않을 경우 NO를 출력한다.
 이 후 a부터 b로 시작하는 단어들에 대해 그 단어 뒤의 알파벳에 대한 분석을 진행한다. 예를 들어 abcde로 시작하는 단어일경우 b로 시작하는 단어가 bcde* 형태인지 확인하고 맞을경우 *에 있는 단어를 abced뒤에 이어 붙이고 b에 방문했다고 표시한다. 그렇지 않을 경우 NO를 출력한다.
 그 뒤 방문하지 않은 alphabet들로 시작하는 단어들을 알파벳으로 이어붙이면 사전 순으로 정렬된 답을 얻을 수 있다.

## 복잡도
- 시간: O(n) - 알파벳 수가 26개로 정적이기 때문이다. 
- 공간: O(n) 

## 한 줄 회고
