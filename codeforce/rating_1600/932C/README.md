# Permutation Cycle

## 링크
[문제 바로가기](https://codeforces.com/problemset/problem/932/C)

## 사용 알고리즘
- 단순 계산

## 풀이
- 해당 문제는 모든 배열이 A또는 B의 길이만큼으로 이루어진 사이클로 구성되어야 한다. A*num + B * another_num = N 이 만족하는지 확인하고 만족한다면 사이클이 구성되도록 순열을 만든다.

## 복잡도
- 시간: O(n) 
- 공간: O(n)
